# Tic, l'app qui t'emmène jusqu'au morceau que tu veux jouer

![Tic](docs/img/banner.png)

Tic est une app mobile pour apprendre le piano (la guitare viendra ensuite) autour d'un objectif concret : le morceau que tu as envie de jouer. L'app le découpe en parties, propose chaque jour une séance courte dont tu choisis la durée, et rend tes progrès visibles. Elle t'écoute jouer par le micro du téléphone, ou par un clavier MIDI si tu en as un. Sa mascotte est un métronome, Tic.

Tic s'adresse aux débutants, à ceux qui reprennent un instrument après une pause, et à ceux qui cherchent un support pour rester motivés.

Ce dépôt contient la **Phase 1 (Ideation, T7)** du projet de fin d'études Epitech. Règle de la phase : zéro code produit, le terrain d'abord, et pivoter si les entretiens invalident le problème.

## Publier la vitrine

1. Sur GitHub : **Settings > Pages > Build and deployment**, source « Deploy from a branch », branche `main`, dossier `/docs`, puis **Save**.
2. Après une à deux minutes, la vitrine est en ligne à l'adresse `https://<compte>.github.io/<depot>/`.
3. Coller cette adresse dans la fiche Tic de la plateforme Innovation.

Les éléments encore à compléter dans la vitrine sont repérés par des commentaires `À REMPLIR` et `À REMPLACER` dans `docs/index.html`.

## Données personnelles
